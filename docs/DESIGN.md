# ダッシュボード改修 設計書(2026-10-20)

## ゴール
毎朝 7:00〜9:00 にダッシュボードを開いたとき、**前日(米国)の終値・先物カーブがすべて反映されている**こと。

## 調査で分かったこと

| # | 症状 | 実際の原因 |
|---|---|---|
| 1 | 10/20朝に開いても「データ: 10/16(金)終値」のまま | ①CboeのCSVは引けから**1日以上**遅れて反映される(10/20 9:40時点でもVIX・先物とも10/16まで)。VIX・VIX3M・SKEWだけは delayed_quotes で補っていたが、**先物・SPX・VIX9D・地合いシグナルは補っていなかった** ②GitHub Actions の定時実行が大幅に遅れる(7:50指定 → 実際は9:30〜9:50、18:50指定 → 21:00〜翌1:40) |
| 2 | 「バックワーデーション」表示なのに調整金はプラス | 主因は上の古いデータ。10/16は急騰日で期近19.91 > 次限月19.24の逆ザヤだった。**10/19の清算値では期近18.16 → 次限月18.60で+2.4%の順ザヤ**。当初「ロール日の影響」と説明したが、ロールの切り替え規則(満期の前日)自体は変えていない |
| 3 | 上部は「バックワーデーション」、日次ログは「コンタンゴ」 | 見ている指標が別(上部=先物1〜2限月、日次ログ=VIX3M÷VIX)。見出しで区別できていなかった |
| 4 | 「次のロール 4日」(実際は当日) | データ日付(10/16)から数えていた |
| 5 | 日次ログの重複行(9/21=9/22 など) | 2026/8〜10初旬のパソコン時代の記録が**1日ずれて**書かれていた(実行日を日付にしていた)。土曜(8/8)の行も混入 |
| — | 経済指標カレンダー・次の最重要指標が空 | 誤認。ブラウザのJSで描画しているため、ページ取得ツールで見えなかっただけ |

## 改修内容

### A. 朝の時点で前日分を全部そろえる(`fetch_signals.py`)
- VIX・VIX3M・VIX9D・SKEW・SPX の5指数すべてを delayed_quotes の公式終値で補い、**基準日そのものを最新の米国営業日にする**(地合いシグナル・ストレステストも同じ日の値で計算)。
- 先物は日付指定の清算値CSV(`www.cboe.com/us/futures/market_statistics/settlement/csv?dt=`)で当日分を補う。未清算の日付を指定すると直近値が返る仕様なので、**前営業日と同じ値なら未反映**とみなして使わない。
- 調整金カードに「期近→次限月の値」「参考: 2〜3限月のコンタンゴ率」「何日の清算値か」を表示。

### B. 表示の整理(`update_dashboard.py`)
- 日次ログの列名を「VIX3M÷VIX」「3ヶ月先との関係」に変更し、上部の先物判定と別物だと分かるようにした。
- 価格調整日・次のロールの残り日数を、**閲覧した日(日本時間)**から数えるように変更。
- log.csv は毎回、記録開始(2025/8)以降の全期間をCboe確定値で書き戻し、営業日でない行は削除。→ 今回38行を修正、2行(非営業日)を削除。

### C. 更新タイミング
| 実行元 | 時刻(日本時間) | 役割 |
|---|---|---|
| Claudeのクラウドのスケジュールタスク | 毎日 6:45 | **主役**。時刻どおりに動く(実績: 6:45:14起動)。既存の「見通し更新」タスクの最初に数値更新を追加 |
| GitHub Actions | 月〜土 6:23 / 6:53 / 7:23 | 予備。遅れても、どれか1回で追いつく |

- どちらも `scripts/run_update.sh` を呼ぶ。数値が変わらなければコミットしない。push が競合したら最新の main に合わせて作り直す。
- データ遅延バッジの基準を「7:30 までに前日分」に変更。

## 仕様上の限界(許容いただく点)
- **米国の冬時間(11/2〜)はVIXの確定が日本時間6:15、SKEWの確定が7:00頃**。VIX・先物は6:45の実行で間に合う想定。SKEWだけは冬の間、6:45時点では前日値になり 7:23 の予備実行で追いつく(SKEWは判断の軸ではないので許容)。Cboe側の反映が遅れた日は画面上部の注記・バッジで分かる。
- 先物の清算値ファイルが朝までに出ていない日は、先物だけ前営業日の値になる(画面上部に注記が出る)。
- 推定調整金はあくまで回帰式による推定。今回の実測(+4.25円/lot/日)に対し、10/19の清算値での推定は+1.98円。ロール直前・急変直後はずれやすい。実測値が数回たまったら式を見直す。
- GitHub Pages の反映に push 後1〜2分かかる。
